# 史料读书笔记网站 — 需求说明书

## 角色
你是一个搭建个人博客网站的人，擅长搭建界面简洁美观的网站页面。

## 背景
我是一个读书爱好者，正在阅读一些史料，希望能搭建一个完成史料读书笔记的网站。

## 任务
生成一个能完成读书笔记的单页网站。

## 核心数据模型
1. **笔记**：每条笔记包含三个维度
   - 时间（自由文本，如"万历十五年"）
   - 事件（发生了什么）
   - 感受（我的想法与感悟）
2. **合集**：可自由创建的主题分组（如"明史拾遗"），笔记可选择是否加入合集
3. **未加入合集的笔记**：独立存在的笔记，不属于任何合集

## 页面功能要求

### 首页（笔记列表页）
- 左侧栏导航：全部笔记 / 未加入合集 / 各合集
- 右侧主区域展示笔记三栏表格：
  - 最左侧：时间（竖直排列，居中显示）
  - 中间：事件
  - 最右侧：感受
- 时间、事件、感受一一对应，排成一行
- **同一时间点多事件**：用左大括号 `{` 连接，大括号位于时间点右侧
- **同一时间点多事件**：事件行之间用虚线横线分隔
- 首页事件和感受最多展示 **50 字**，超出截断加省略号
- 同一个时间点内，合集标签只显示 **一个**，放在该时间点第一行左上角

### 笔记详情 / 编辑页
- 可新建、编辑、删除笔记
- 新建时可选择加入哪个合集（或不加入）
- 编辑时展示完整内容（不受 50 字限制）

### 合集管理
- 自由创建、编辑、删除合集
- 删除合集时，其中的笔记变为「未加入合集」

## 视觉规范

### 配色
- 整体素雅，不用莫兰迪色系
- 主色调：暖白底、浅米卡片、近黑文字、柔和灰边框
- **角落跳脱色**（仅小面积使用）：
  - 合集标签：玫红 `#E85F6E`、琥珀 `#D9944E`、青绿 `#5BA68A`、钴蓝 `#5B8DB8`、紫罗兰 `#7A6FA8`、粉 `#D67A9A`、芥末 `#C4A43B`、青蓝 `#4A9A9E`
  - 大括号：玫红 `#E85F6E`
  - 空状态图标：玫红
  - 侧栏「未加入合集」圆点：琥珀色 `#D9944E`

### 布局细节
- 事件文字直接作为格子首个内容节点，从格子第一行开始显示
- 事件与感受的首行文字必须在同一水平线上
- 每列虚线要对齐（用 background-image 模拟，避免 border 叠加错位）
- 三栏列宽比例：时间 200px / 事件 1fr / 感受 1fr

## 交互规范
1. **浏览器后退键**：通过 history.pushState + popstate 实现站内后退，不按后退时跳出网站
2. **响应式**：
   - 笔记本（≥981px）：完整三栏布局
   - 平板（≤980px）：三栏紧凑布局，时间列缩窄
   - 手机（≤720px）：单列堆叠，时间在上，事件/感受依次排列
   - 触摸友好：按钮 min-height 44px，输入框 16px 字号（避免 iOS 焦点缩放）
3. **跨设备同步**：
   - 提供「导出 JSON」按钮：下载全部数据
   - 提供「导入 JSON」按钮：从文件恢复数据
   - 同浏览器多标签页通过 storage 事件实时同步

## 技术约束
- 纯前端实现（HTML + CSS + JS），无后端
- 数据持久化：浏览器 localStorage
- 单页应用（SPA），无页面刷新

## 输出格式
一个可直接部署的网站文件夹（index.html + styles.css + app.js）。
